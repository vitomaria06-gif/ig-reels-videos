Reels-Upload

Reels-Upload ist eine kleine private Automatik von Vito. Sie lädt selbst erstellte Kurzvideos (Reels/Shorts) zu festen Uhrzeiten auf den eigenen YouTube-Kanal des Betreibers hoch.

Die App ist nicht öffentlich nutzbar. Es gibt nur einen Nutzer: den Betreiber selbst. Es werden keine Daten anderer Personen gelesen oder gespeichert.
