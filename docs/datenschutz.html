Datenschutzerklärung – Reels-Upload

Stand: 03.11.2026

Was die App macht

Reels-Upload ist eine private Automatik des Betreibers (Vito). Sie nutzt die YouTube Data API ausschließlich mit dem Recht „Videos hochladen“ (youtube.upload), um selbst erstellte Videos auf den eigenen YouTube-Kanal des Betreibers hochzuladen.

Welche Daten verarbeitet werden

Es werden nur die Videodateien, Titel und Beschreibungen verarbeitet, die der Betreiber selbst hochladen möchte. Die App liest keine Daten anderer Personen. Der Zugangsschlüssel (Token) für den eigenen Kanal liegt in geschützten Werten des privaten Betreiber-Projekts und wird an niemanden weitergegeben.

Weitergabe und Speicherung

Es erfolgt keine Weitergabe an Dritte, kein Verkauf von Daten und keine Werbung. Die App speichert keine Nutzerdaten über die Videos hinaus.

Google API-Dienste

Die Nutzung von Informationen, die von Google APIs stammen, entspricht der Google API Services User Data Policy, einschließlich der Anforderungen zur eingeschränkten Nutzung.
